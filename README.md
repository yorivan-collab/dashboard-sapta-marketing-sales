# Sapta Mutu Utama — Leads Workspace

Dashboard internal buat tim sales PT Sapta Mutu Utama: nyimpen data lead, follow-up, produk/omzet, sampai monitoring tim. HTML (`leads-dashboard-prototype.html`) + file tampilan (`theme-default.css`) + database Supabase di belakangnya.

## Isi folder ini

**File utama (yang beneran dipakai):**

- `leads-dashboard-prototype.html` — aplikasinya (struktur halaman + semua logic). Buka di browser buat pakai.
- `theme-default.css` — **file tampilan/desain default** (warna, bentuk kartu, jarak, font). Dipisah dari file utama supaya gampang diganti-ganti kalau nanti mau restyle total tanpa nyentuh logic. Ini yang aktif dipakai sekarang -- JANGAN ditimpa, biar selalu ada versi "aman" buat balik lagi kalau tema lain nggak cocok.
- `theme-semangat-sales.css` — **tema alternatif**, sama persis kayak `theme-default.css` tapi background area kanan (bukan sidebar) diganti gradient hangat (peach-pink-ungu muda), biar kesannya lebih "semangat" buat tim sales, nggak flat/redup kayak warna default. Belum aktif dipakai -- masih nunggu ada fitur ganti tema di aplikasi (lihat bagian "Rencana ke depan" kalau ada), atau bisa dicoba manual dengan ganti baris `<link rel="stylesheet" href="theme-default.css">` di `index.html`/`leads-dashboard-prototype.html` jadi `href="theme-semangat-sales.css"`.
- `README.md` — file ini.
- `panduan-alur-kerja-dan-roadmap-supabase.docx` — penjelasan konsep arsitektur (Cowork/GitHub/Vercel/Supabase) dan roadmap menuju launching.
- `catatan-perjalanan-leads-dashboard.docx` — catatan histori pengembangan.
- `alur_navigasi_leads_dashboard.png` / `.svg` — diagram alur navigasi aplikasi.

**Data uji coba (opsional, bisa dijalankan kapan pun) -- PAKAI YANG INI:**

## Setup Supabase (urutan dari nol)

Kalau harus setup ulang dari database kosong, jalankan file-file ini satu-satu di **SQL Editor** Supabase, sesuai urutan:

1. **Bikin 4 akun dulu** di Authentication → Users (email + password), baru lanjut ke SQL.
2. `supabase-reset-dan-setup-lengkap.sql` — bikin tabel `profiles`, `branches`, `leads`, `activity_log`, aturan keamanan (RLS), dan isi 4 profil (Master Admin, Super Admin, Supervisor, Sales). **Perlu disesuaikan dulu**: ganti UID di file ini sesuai UID akun Authentication yang baru dibikin.
3. `supabase-tambah-chatlog.sql` — nambah kolom "Chat Log" di tabel leads.
4. `supabase-tambah-changed-by.sql` — nambah kolom pencatat siapa yang mengubah tiap log aktivitas.
5. `supabase-tambah-monitoring-user.sql` — nambah kolom buat fitur Monitoring User (siapa aktif/diam/offline).
6. `supabase-tambah-photo-url.sql` — nambah kolom link foto profil.
7. `supabase-migrasi-leads-lama.sql` — isi data 33 lead asli (dari histori Airtable). Jalankan **sekali saja**, jangan diulang (bakal kedobel).
8. `supabase-tambah-akses-lead-milik-sendiri-supervisor.sql` — opsional, cuma perlu kalau Supervisor bikin lead atas nama dirinya sendiri.
9. `supabase-tambah-admin-requests.sql` — bikin tabel buat alur "Supervisor ajukan admin baru → Master/Super Admin approve".
10. Deploy `supabase-edge-function-approve-admin-request.ts` lewat Supabase Dashboard → Edge Functions (bukan SQL Editor).
11. Deploy `supabase-edge-function-create-user-account.ts` lewat Supabase Dashboard → Edge Functions juga.
12. `supabase-tambah-detail-profil.sql` — nambah kolom Jabatan, Cabang (label doang), Nomor telepon, Bio singkat -- dipakai di kartu Profile menu Dashboard, bisa diisi/diedit sendiri sama tiap user.
13. `supabase-tambah-pic-source.sql` — nambah kolom "Tipe PIC" (Internal / Jaringan luar-broker) di tabel leads.
14. `supabase-tambah-storage-foto-profil.sql` — bikin tempat penyimpanan (Storage bucket) buat foto profil, biar upload foto langsung dari aplikasi, gak perlu hosting di tempat lain (Imgur, dll) lagi.
15. `supabase-tambah-status-lead-baru.sql` — nambah kolom `first_viewed_at` di leads, buat nandain lead yang belum pernah dibuka (titik hijau) vs udah pernah dibuka (titik kuning).
16. `supabase-super-admin-bisa-hapus-lead.sql` — ubah aturan keamanan (RLS) tabel leads biar Super Admin juga bisa hapus lead, bukan cuma Master Admin. **Wajib dijalanin** biar tombol "Hapus lead" beneran nyala buat Super Admin -- kalau cuma aplikasinya yang diupdate tanpa jalanin ini, tombolnya muncul tapi hapusnya bakal ketolak sama database.
17. ~~`supabase-tambah-perbantuan-lead.sql`~~ — **JANGAN DIJALANIN.** Ini buat fitur "Bagikan lead" (Perbantuan/Full kelola) yang udah DIBATALKAN/dicabut lagi dari aplikasi karena kerasa ribet. Kalau kamu sempat menjalankan file ini sebelumnya, jalankan `supabase-batalkan-perbantuan-lead.sql` buat ngebalikin database ke kondisi semula. Kalau belum sempat jalanin, abaikan aja kedua file ini.
18. `supabase-tambah-limit-kuota.sql` — bikin tabel `quota_requests` buat fitur batasan jumlah data (maks 2 produk/lead, maks 10 follow-up/lead/hari, maks 15 lead/admin) + alur request tambahan limit ke Master/Super Admin. **Wajib dijalanin** biar menu "Permintaan Limit" jalan -- tanpa ini, request tambahan limit bakal error karena tabelnya belum ada.
19. `supabase-aktifkan-realtime-activity-log.sql` — daftarin tabel `activity_log` ke publication Realtime Supabase. **Wajib dijalanin** biar pop-up notifikasi live (lihat bagian Menu di bawah) beneran nyala -- tanpa ini bukan error, tapi pop-up-nya gak akan pernah muncul sama sekali (diem aja, gak ada tanda apa-apa).

Semua file SQL di atas aman dijalankan ulang kapan pun (pakai `if not exists`), **kecuali** nomor 7 (migrasi data) yang bakal bikin data dobel kalau dijalankan dua kali.

## Peran & akses

| Role | Bisa lihat data siapa | Bisa kelola user | Bisa hapus lead |
|---|---|---|---|
| Master Admin | Semua | Semua, termasuk Super Admin | Ya |
| Super Admin | Semua kecuali Master Admin | Supervisor & Sales saja | Ya |
| Supervisor | Dirinya + anggota tim yang ditugaskan | Tidak | Tidak |
| Sales | Cuma lead miliknya sendiri | Tidak | Tidak |

Login pakai email + password lewat Supabase Auth. Lupa password: hubungi Master Admin buat direset manual lewat Supabase Dashboard (bukan lewat aplikasi).

## Menu yang ada

- **Overview** — kartu statistik, grafik, tabel performa; datanya sesuai scope role (Sales cuma lihat punya sendiri, Supervisor timnya, Master/Super Admin semua), bisa difilter & dicari. Grafik "Pertumbuhan leads & closing rate" sekarang ada batang "Total lead baru" biar langsung keliatan sejauh mana penambahan lead per periode, gak perlu jumlahin manual garis Hot/Warm/Cold.
- **Sidebar** — nama perusahaan sekarang "Sapta Mutu Utama" (lengkap), dan di bawah "Leads workspace" ada nama user yang lagi login (warna ungu muda), biar keliatan lagi login sebagai siapa tanpa buka menu lain.
- **Field Harga Penawaran & Realisasi Omzet (di form produk lead, penuh maupun popup cepat)** — sekarang otomatis kasih titik pemisah ribuan begitu ngetik (misal ketik "52000000" langsung kebaca "52.000.000"), biar gampang ngecek jumlah nol-nya sebelum simpan. Sebelumnya kotak angka polos tanpa pemisah, gampang salah hitung nol atau kepotong kalau ngetik titik/koma manual sebagai pemisah ribuan.
- **Harga Deal dihapus, diganti "Realisasi Omzet" + "Sisa Realisasi" otomatis** — kalau klien nego harga, tinggal ubah langsung angka "Harga Penawaran"-nya, gak ada field harga deal terpisah lagi. Field "Realisasi Omzet" isinya jumlah uang yang BENERAN udah masuk (DP maupun lunas, gak dibedain lagi lewat checkbox manual). Sisa realisasi (Harga Penawaran dikurangi Realisasi Omzet) dihitung dan ditampilin otomatis, baik di form produk maupun di kartu produk yang udah tersimpan (badge "Lunas" hijau kalau sisa realisasi Rp0, badge "Sisa realisasi Rp..." kuning kalau masih ada sisa). Checkbox "Tandai sudah lunas" udah dihapus -- status lunas sekarang murni hasil hitungan, bukan ditandain manual. Sebuah lead otomatis dianggap "Sudah Closing" begitu Realisasi Omzet-nya lebih dari Rp0, gak peduli udah lunas penuh atau baru DP.
- **Daftar produk yang udah ditambahkan ke lead** — tampilannya sekarang berupa kotak/blok jelas (border + background), bukan baris tipis nyempil kayak sebelumnya, biar keliatan lebih "berarti" datanya. Tombol hapus produk (ikon silang) sekarang munculin konfirmasi "Anda mau hapus penawaran ini?" dulu sebelum beneran kehapus -- gak bisa kepencet gak sengaja lagi.
- **Ketik di kolom Jenis Produk/Harga Penawaran/Realisasi Omzet tapi lupa klik "+ Tambah produk"** — sekarang ikut kena peringatan "Anda melakukan perubahan, apakah mau simpan lead?" kalau kamu coba pindah halaman/tutup lead tanpa nge-klik tombol itu dulu. Sebelumnya isian di kolom ini kalau lupa di-"Tambah produk"-kan bakal hilang diam-diam tanpa peringatan sama sekali.
- **Dropdown "Admin Sales" (siapa pemilik lead)** — kalau login sebagai Master/Super Admin, sekarang nampilin SEMUA user aktif apa pun rolenya (Master Admin, Super Admin, Supervisor, Sales), bukan cuma Sales + diri sendiri kayak sebelumnya. Tiap nama di dropdown ini juga dikasih label perannya, contoh "Aulia - Super Admin", "Andi - Supervisor", "nilam - Sales", biar gampang bedain siapa itu tanpa harus buka menu Kelola Pengguna. (Supervisor & Sales tetap kekunci ke lingkup mereka sendiri kayak biasa -- ini cuma buat yang login Master/Super Admin.)
- **Filter "Rencana omzet" di Leads** — chip ringkasan total omzet di atas list ("Rencana omzet · N lead · total Rp ...") sekarang gak bisa ditutup/dihapus (gak ada tombol "x") selama filter ini aktif, biar konteksnya gak ilang. Kolom "Tanggal input" di list-nya juga otomatis ganti jadi "Nilai omzet", nampilin total Harga Penawaran per lead -- lebih relevan buat ngecek besaran rencana omzet per klien dibanding tanggal input-nya. Kolom Follow up tetap ada seperti biasa.
- **Perbandingan Kinerja** — kartu "Omzet closed" yang dulu satu kotak lebar sekarang dipecah jadi dua: "Rencana omzet" (total harga penawaran) dan "Realisasi Omzet" (total realisasi omzet), sejajar kayak kotak lainnya. Kotak Cold/Warm/Hot/Sudah Closing/Rencana omzet/Realisasi Omzet sekarang dikasih warna sesuai temanya (Cold abu-abu, Warm kuning, Hot merah + kedap-kedip, Sudah Closing & Realisasi Omzet hijau, Rencana omzet ungu), biar gampang dipindai sekilas. Tampilan kartunya juga dipercantik dikit (bayangan lembut, sedikit efek hover, foto profil dikasih cincin warna).
- **Dashboard** — menu paling atas dan halaman default begitu login. Di samping judul "Dashboard" ada garis pemisah dan sapaan "Halo, [nama user]!" warna ungu, biar berasa personal tiap buka. Isinya cuma data lead milik sendiri, terkunci (gak ada filter/pencarian). Ada kartu Profile (foto, nama, role, tombol "Edit profil" buat isi Jabatan/Cabang/Nomor telepon/Bio singkat sendiri, ganti password sendiri, info tim/supervisor, ringkasan total lead/closing rate/omzet pribadi) yang nempel pas di-scroll, plus 7 kartu ringkasan (Total lead, Sudah Closing, Follow up telat, Belum ada interaksi, Rencana omzet, Realisasi Omzet, Sisa Realisasi) dan kartu Cold/Warm/Hot -- semuanya bisa diklik, langsung buka Leads yang sudah difilter dan dikunci ke lead sendiri.
- **Filter rentang tanggal (Overview & Leads)** — mirip filter tanggal Airtable tapi disederhanain jadi satu date-range picker: pilih dulu field-nya (Tanggal input lead, atau Tanggal follow-up), lalu isi tanggal "dari" dan "sampai". Muncul di toolbar filter Overview maupun Leads (sejajar dropdown PIC/lokasi/admin yang udah ada), dan ikut mempersempit angka di kartu-kartu Overview juga, bukan cuma daftar lead-nya. Ada tombol "Reset tanggal" yang muncul otomatis kalau filter ini lagi aktif. (Dashboard di menu paling atas TETAP terkunci ke data sendiri tanpa filter apapun, sesuai desain awalnya.)
- **Leads** — daftar lengkap, bisa difilter, dikelompokkan per admin, dan diedit. Field "Nama PIC" sekarang ada saran otomatis dari nama-nama PIC yang udah pernah dimasukin sebelumnya (biar gampang ketauan kalau PIC-nya sama kayak lead lain), plus field baru "Tipe PIC" (Internal / Jaringan luar-broker) buat nandain kalau kontaknya itu bukan orang perusahaan langsung, tapi broker/calo yang nyariin klien. Perubahannya kecatet otomatis di Log Aktivitas kayak field lain.
  - **Banner "Filter aktif" (baru, 2026-09-24)** — muncul otomatis di atas tabel begitu ada filter yang lagi nyala (status, PIC, lokasi, campaign, rentang tanggal, kata pencarian, admin yang dipilih manual, atau Fokus tampilan), nampilin ringkasan singkat semuanya dalam satu baris ungu dengan titik kecil yang berkedip pelan terus-menerus -- biar kelihatan/keinget tanpa harus norak. Ada tombol "Reset semua" buat langsung balikin semua filter itu ke default sekaligus (kecuali Fokus tampilan -- itu resetnya tetap lewat badge "Fokus: ..." sendiri karena preferensinya lintas-menu, bukan cuma di Leads). Banner ini otomatis ilang kalau semua filter emang lagi kosong/default.
  - **Tombol "+ Tambah lead" sekarang buka popup kecil** (bukan pindah halaman/panel penuh lagi), khusus buat nambah lead baru dengan cepat. Yang bener-bener wajib ada 3: Suhu lead, Nama PIC, dan Laporan follow up awal -- kalau salah satu kosong, muncul peringatan dan gak bisa disimpan. Nomor telepon dan nama perusahaan tetap opsional, boleh kosong kalau belum tentu ada. Nama perusahaan boleh kosong dulu -- kalau PIC-nya udah diisi, otomatis dikasih nama sementara `- (PIC: nama 1)` (nomor urut per PIC, biar gak nabrak kalau PIC yang sama bawa beberapa perusahaan yang belum ketahuan namanya). Kalau nama perusahaan yang diketik sama persis kayak lead lain, muncul peringatan kecil di bawah field-nya (bukan diblokir, cuma diingetin). Field admin sales otomatis ke-skip buat Sales (gak perlu milih, udah pasti atas nama sendiri) tapi tetap muncul buat Supervisor/Master/Super Admin buat nentuin siapa pemiliknya. Alamat, kota, provinsi, email, dan sumber lead dikumpulkan di bagian "Lengkapi nanti" yang bisa dilipat. Produk (jenis + harga penawaran) opsional di popup yang sama -- begitu diisi terus klik "Simpan lead", otomatis jadi produk pertama, gak perlu langkah kedua.
  - **Bagian "Lengkapi nanti" sekarang SELALU kebuka otomatis begitu buka detail lead yang udah tersimpan** (baru maupun data lama/dummy), biarpun field di dalamnya kosong -- gak perlu diklik manual lagi. Yang tetap tertutup default cuma pas lagi ngisi form TAMBAH lead baru (belum ada datanya sama sekali).

Data lama (sebelum perubahan ini) tetap ada di riwayat, cuma cap waktunya pakai tanggal+jam yang dulu diketik manual (satu-satunya data yang ada buat entri lama).
  - **Buka/edit lead yang udah ada** tetap seperti biasa: klik salah satu lead di daftar, panel penuh geser dari samping (chat log, riwayat follow-up lengkap, daftar produk, dst) -- gak berubah, cuma yang berubah alur nambah lead BARU-nya aja.

Tujuannya biar sales yakin datanya beneran kesimpen walau ninggalin HP sebentar. Highlight-nya baru ilang kalau buka lead lain atau nambah lead lain lagi -- persis mekanisme highlight kuning "Baru dibuka" yang udah ada duluan, cuma beda warna dan pemicu (nambah baru vs buka yang lama).

  - **Kolom tanggal input sekarang nampilin jam juga** (di bawah tanggalnya), bukan cuma tanggal doang.
  - **Filter baru "Tanggal follow up kosong"** (lead yang belum ada rencana follow-up-nya sama sekali) -- ada di submenu sidebar grup "Follow up" (di bawah "Belum ada interaksi"), di menu mobile, dan juga muncul sebagai baris list memanjang (bukan kotak KPI) di bawah kartu Cold/Warm/Hot pada Overview dan Dashboard, biar gak ganggu tata letak kotak yang udah ada. ## Cara deploy (biar bisa diakses lewat link)

Sekarang udah pakai jalur GitHub + Vercel (auto-deploy):

1. Repo GitHub (project "Dashboard Marketing - Sales") isinya file `index.html` (salinan dari `leads-dashboard-prototype.html`) **dan** `theme-default.css` -- dua-duanya harus ada bareng, `index.html` gak akan tampil bagus tanpa file CSS-nya.
2. Tiap mau update: buka repo di GitHub → "Add file" → "Upload files" → drag `index.html` (dan `theme-default.css` kalau itu yang berubah) dari folder ini → Commit changes.
3. Vercel otomatis build ulang sendiri abis commit masuk, gak perlu buka Vercel sama sekali.

**Penting buat sekali ini aja**: karena file CSS-nya baru dipisah, pastikan `theme-default.css` udah ke-upload ke repo GitHub minimal sekali (upload bareng `index.html` yang terbaru). Update-update berikutnya, kalau cuma ganti logic/field (bukan tampilan), cukup upload `index.html` doang.

(Alternatif kalau belum ada GitHub sama sekali: `vercel.com/drop`, drag file HTML langsung, tapi tiap update harus di-drop ulang dan bikin link baru -- gak auto-update kayak jalur GitHub.)

## Keterbatasan yang masih ada

- **Edit user yang udah ada** (ganti nama/role/tim/atasan/branch) sekarang **beneran ke-save ke database**, gak simulasi lokal lagi -- ini baru dibenerin bareng fitur atasan/struktur di atas. Satu pengecualian: **ganti email** pas edit user belum didukung (field-nya sengaja dikunci/disabled) -- ganti email login harus lewat cara lain (belum ada di aplikasi ini), soalnya email login itu diatur di Supabase Auth, beda tempat sama data profil biasa.
- **Ganti password sendiri** sekarang udah bisa (tombol "Ganti password" di kartu Profile, Dashboard). Kalau lupa password dan gak bisa login sama sekali, itu tetap harus direset manual sama Master Admin lewat Supabase Dashboard (Authentication → Users → pilih orangnya → reset password).
- **Upload foto profil sekarang beneran upload file** (klik foto di kartu Profile atau di pojok kiri bawah sidebar), langsung tersimpan di Supabase Storage -- gak perlu hosting eksternal (Imgur, dll) lagi. Maks 2MB per foto, format gambar apa aja (JPG/PNG/dst). Ada juga tombol "Hapus foto" kecil di bawah foto kalau mau balik ke inisial nama.
- **Celah keamanan RLS -- sudah ditutup (2026-08-06)**: audit keamanan nemu 3 lubang dan udah dipatch langsung ke database (lihat `supabase-patch-keamanan-rls.sql` buat arsip, gak perlu dijalanin manual lagi). (1) Sebelumnya siapapun yang login bisa update baris profilnya sendiri tanpa batasan kolom -- termasuk ubah `role` jadi master_admin, ubah `name` buat nyaplok akses lead orang lain, atau ubah `team`/`branch`/`email` -- sekarang dikunci pakai database trigger, cuma master_admin yang boleh ubah kolom-kolom itu. (2) Super Admin sebelumnya bisa bikin akun baru dengan role master_admin/super_admin lewat insert langsung -- sekarang dibatasi cuma boleh bikin sales/supervisor, sama kayak batasan pas edit. (3) Tabel `activity_log` (basis fitur notifikasi live) sebelumnya bisa diisi siapa aja buat lead manapun dengan identitas `changed_by` bebas diisi apa aja -- sekarang dikunci cuma boleh log lead yang emang bisa diakses, dan `changed_by` wajib nama sendiri.
- **Belum sempat dibenerin (perlu ke Supabase Dashboard langsung, bukan lewat kode)**: "Leaked Password Protection" di Authentication masih OFF -- fitur ini ngecek password baru user lawan daftar password bocor (HaveIBeenPwned). Tinggal nyalain di Supabase Dashboard → Authentication → Policies/Providers, gak butuh perubahan kode apa-apa.
- **Import data JSON** cuma nampilin sementara di layar, belum tersimpan ke server (fitur lama, belum disambungin ke Supabase).
- **Batasan limit (produk/follow-up/jumlah lead)** dicek di aplikasi pas mau nyimpen, bukan dijaga ketat di level database -- kalau dua orang nyimpen hampir bersamaan dari dua perangkat beda, ada kemungkinan kecil batasnya kelewat 1 sebelum keduanya sempat lihat pesan limitnya. Buat pemakaian sehari-hari (satu orang, satu waktu) ini gak masalah.
- **Notifikasi live** butuh koneksi internet yang nyala terus (WebSocket) -- kalau lagi putus-putus, pop-up bisa aja gak nyampe (gak ada tanda error, cuma diem aja). Data aslinya tetap aman/gak hilang, cuma pop-up-nya doang yang mungkin kelewat -- begitu dibuka lagi datanya tetap up to date kok.
- Belum ada auto-deploy dari GitHub — tiap update kode masih manual (drag-drop ulang ke Vercel, atau lewat Cowork/Claude Code).
- **Bug ketemu & dibenerin (2026-09-08): tombol "+ Tambah lead" kadang harus diklik berkali-kali.** Penyebabnya kotak notifikasi live "Ada perubahan di lead ..." (`#live-notify-toast`, pojok kanan-atas layar) -- CSS-nya salah setting, bikin dia tetap bisa "nangkep" klik mouse walau lagi nggak keliatan/nggak ada notif, padahal posisinya numpuk sama tombol "+ Tambah lead" yang sama-sama di pojok kanan-atas. Klik yang jatuh di area situ ketangkep sama kotak notif yang nggak keliatan itu duluan (gak ngapa-ngapain, makanya nggak ada error), bukan sampai ke tombolnya. Sekarang dibenerin: kotak notifnya cuma "bisa diklik" pas dia beneran lagi nongol doang.
